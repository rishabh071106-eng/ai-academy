The Back of the Book

The AI Dictionary

Every big word from the book, in plain language — now they're yours.

Activation
The signal a neuron sends on once it has added up its inputs — like a tiny light switch deciding whether to fire or stay quiet. (see Class 9)
Agent
An AI that doesn't just answer — it takes actions, sees what happens, and tries again to reach a goal, like a player learning a game. (see Class 15)
Algorithm
A step-by-step recipe for solving a problem. Every AI is built out of algorithms, just like every cake is built out of recipes. (see Class 1)
Alignment
Making sure an AI actually wants to do what humans want it to do — not just what we accidentally told it to do. (see Class 20)
Artificial Intelligence
Machines doing things that usually need a brain — like seeing, talking, choosing, or learning. We just call it AI for short. (see Class 1)
Attention
A clever trick that lets an AI decide which words in a sentence matter most for understanding each other word. (see Class 14)
Backpropagation
How a neural network learns from a mistake: it traces the error backward through every layer and nudges each weight a little. (see Class 10)
Bias
When an AI is unfair to certain people or groups, usually because the data it learned from was unfair too. (see Class 19)
Centroid
The center point of a cluster — like the middle of a huddle of friends. Clustering keeps moving centroids until they sit right. (see Class 6)
Classification
Sorting things into named groups, like "cat or dog" or "spam or not spam." The AI picks which box each thing belongs in. (see Class 4)
Clustering
Letting an AI find groups in data all by itself, without anyone telling it the names of the groups first. (see Class 6)
Collaborative Filtering
Recommending things by noticing that people who liked what you like also liked something new — so maybe you will too. (see Class 17)
Computer Vision
Teaching a computer to "see" — to find shapes, faces, and objects inside pictures and video. (see Class 11)
Convolutional Neural Network
A special network for images that slides little filters across a picture to spot edges, patterns, and shapes. Often called a CNN. (see Class 11)
Data
The examples an AI learns from — pictures, numbers, words, sounds. No data, no learning. (see Class 3)
Dataset
A whole collection of data gathered together for an AI to study, like a big notebook full of examples. (see Class 3)
Decision Tree
A flowchart of yes/no questions that leads to an answer, like a game of "20 Questions" the computer plays. (see Class 4)
Deep Learning
Machine learning using neural networks with many layers stacked deep — which is how AI got so powerful. (see Class 9)
Diffusion
A way to make new images by starting with pure static and slowly cleaning it up until a picture appears. (see Class 18)
Epoch
One full trip through all the training examples. Models usually need many epochs to learn well. (see Class 10)
Error (Loss)
A number that measures how wrong the AI's guess was. Learning means making this number as small as possible. (see Class 10)
Explore vs Exploit
The tug-of-war between trying something new (explore) and sticking with what already works (exploit). (see Class 15)
Fairness
Building AI so it treats different people justly and doesn't hand out unfair results. (see Class 19)
Feature
One measurable detail about an example — like a fruit's color, weight, or size — that the AI uses to decide. (see Class 3)
Filter
A tiny pattern-detector that slides across an image looking for one thing, like an edge or a corner. (see Class 11)
Generalization
When an AI handles brand-new examples it never saw in training. That's the real goal — not just memorizing. (see Class 8)
Generative AI
AI that creates new things — text, pictures, music — instead of just sorting or labeling what already exists. (see Class 18)
Gradient Descent
The way a model rolls "downhill" toward smaller error, taking small steps in the direction that helps most. (see Class 10)
Graph
A web of dots (places or things) joined by lines (connections). Maps and friend networks are graphs. (see Class 16)
Guardrails
Rules and limits built around an AI to keep it from doing harmful or dangerous things. (see Class 20)
Hallucination
When a language model says something made-up with total confidence, as if it were true. Always double-check. (see Class 13)
Heuristic
A smart shortcut or rule of thumb that usually works — like guessing the way to a goal instead of checking every path. (see Class 16)
Impurity
How "mixed up" a group is. A decision tree asks questions that lower impurity, so each group gets cleaner. (see Class 4)
Label
The correct answer attached to an example, like writing "cat" under a cat photo so the AI can learn from it. (see Class 2)
Language Model
An AI that predicts the next word again and again, which lets it write, chat, and answer questions. (see Class 13)
Layer
One row of neurons in a network. Stacking many layers lets the AI learn bigger, fancier patterns. (see Class 9)
Learning Rate
How big a step the model takes while learning. Too big and it overshoots; too small and it crawls. (see Class 10)
Linear Regression
Drawing the best straight line through dots of data so you can predict numbers, like price from size. (see Class 7)
Machine Learning
Letting a computer learn patterns from examples instead of being given every rule by hand. (see Class 2)
Majority Vote
Deciding by what most of the neighbors say. If 3 of 5 nearby points are "apple," the answer is apple. (see Class 5)
Model
The "brain" an AI builds after training — all the patterns it learned, ready to make predictions. (see Class 2)
Narrow AI
AI that's brilliant at one job but clueless at everything else. All of today's AI is narrow AI. (see Class 1)
Nearest Neighbors
Guessing about a new thing by looking at the most similar things you already know. Birds of a feather! (see Class 5)
Neural Network
A web of simple "neurons" wired together that learns patterns — loosely inspired by the brain. (see Class 9)
Neuron
One tiny unit in a neural network that adds up its inputs and decides how strong a signal to pass on. (see Class 9)
Overfitting
When a model memorizes the training examples too closely and then flunks on anything new. (see Class 8)
Pixel
One of the millions of tiny colored dots that make up a digital picture. To a computer, an image is just numbers. (see Class 11)
Policy
An agent's strategy — its plan for which action to take in each situation it might find itself in. (see Class 15)
Prediction
The model's best guess about something it hasn't been told, like tomorrow's weather or what's in a photo. (see Class 2)
Prompt
The instructions or question you type to an AI. A clear prompt usually gets a better answer. (see Class 13)
Recommendation System
The AI that suggests videos, songs, or products you might like based on what you and others enjoy. (see Class 17)
Regression
Predicting a number (like a price or a score) rather than a category. The opposite job from classification. (see Class 7)
Reinforcement Learning
Learning by trial and reward: try things, get points for good moves, and slowly get better. (see Class 15)
Reward
The points an agent earns for doing something good. Chasing more reward is what teaches it. (see Class 15)
Search
Exploring many possible options or paths to find the best one — like hunting for the shortest route on a map. (see Class 16)
Sequence
An ordered list where position matters — letters in a word, words in a sentence, notes in a song. (see Class 12)
Supervised Learning
Learning from examples that come with the right answers (labels) attached, like flashcards with the back filled in. (see Class 2)
Test Set
Examples kept hidden during training, used afterward to fairly check whether the model really learned. (see Class 8)
Token
A small chunk of text — a word or piece of a word — that a language model reads and predicts one at a time. (see Class 13)
Training
The practice stage where an AI studies examples over and over and adjusts itself to get better. (see Class 2)
Transformer
The powerful kind of neural network behind modern chatbots, built around the idea of attention. (see Class 14)
Underfitting
When a model is too simple to catch the pattern, so it does poorly even on the examples it trained on. (see Class 8)
Unsupervised Learning
Learning from data with no labels at all, hunting for patterns and groups on its own. (see Class 6)
Weight
A number that says how important one connection is in a network. Learning means tuning all the weights. (see Class 9)
