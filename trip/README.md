# Kanyakumari & Padmanabhaswamy — 30 Aug to 6 Sep 2026

Self-contained itinerary page: `kanyakumari-2026.html`. Open it directly in a
browser — no build step, no dependencies, mobile-first, and it prints cleanly
if you want a paper copy for the train.

**The trip:** Sunday to Sunday, Bengaluru → Thiruvananthapuram → Bengaluru by
overnight train, run from **a single base**: five nights in one room at East
Fort, with Kanyakumari, Padmanabhapuram Palace, Varkala and Kovalam all reached
as day trips out and back.

**Why Trivandrum is the base:** Padmanabhaswamy — the point of the trip — is a
ten-minute walk away, so five consecutive mornings are within reach of it. If
the darshan slot fails for any reason, there are four more attempts. Kanyakumari
as a base would put that temple 2.5 hours away against a noon closure.

**What the single base costs:** the cape at dawn and at dusk in one visit.
Kanyakumari is 2–2.5 hrs each way, so the day trip keeps sunset and gives up
sunrise (or, with an 03:30 departure, the reverse — not both).

**Also built around two fixed constraints:**

- Padmanabhapuram Palace is closed Mondays, so it takes Wednesday.
- Sree Padmanabhaswamy shuts 12:00–17:00 daily, so darshan is a morning
  commitment (Thursday), plus a weather section and sea-safety guidance for
  Kovalam, Varkala and the cape.

**Before travelling, re-verify:** train times on IRCTC/NTES (numbers are stable,
timings shift), the darshan slot at booking.sreepadmanabhaswamytemple.org, and
Padmanabhapuram Palace on 04651 250255.
