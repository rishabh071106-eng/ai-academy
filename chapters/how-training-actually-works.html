How Training Actually Works

Forward pass, backward pass, and the surprisingly simple math that teaches a neural network to think.

A guess, a grade, and a correction

Training a neural network is, at its core, a three-step loop:

  1. Make a guess (forward pass).
  2. Measure how wrong the guess was (loss calculation).
  3. Adjust the knobs so the next guess is less wrong (backward pass).

That's it. Everything else — the GPU clusters, the billions of dollars, the 405-billion-parameter models — is just doing this loop an almost incomprehensible number of times. Let's walk through each step as if we could slow the machine down and watch.

The forward pass: data flows in, a prediction falls out

Imagine a network with a job: predict the next word in a sentence. You feed it "The cat sat on the" and you want it to produce "mat" (or at least rank "mat" highly).

During the forward pass, your input tokens travel through the network layer by layer. Each layer is basically a pile of numbers — called weights — and each layer does a specific mathematical operation: multiply the input by the weights, add a bias, apply a nonlinear function (the "activation"), and hand the result to the next layer.

Think of it like a Rube Goldberg machine. Data enters on the left, gets multiplied, squished, combined, and transformed at each stage, until something pops out the right side: a probability distribution over every possible next word.

The network might say: 62% chance the next word is "mat," 8% chance it's "floor," 3% chance it's "refrigerator." That distribution is the forward pass's output.

Here's the important part: on an untrained network, those weights are essentially random. So the first forward pass is garbage. The network might put 0.001% on "mat" and 4% on "elephant." The whole point of training is to fix that.

The loss function: putting a number on wrongness

After the forward pass, we need a single number that captures "how bad was that prediction?" This is the loss.

For language models, the standard choice is cross-entropy loss. Without getting into the math, it essentially says: you told me the right answer was "mat," and you only gave "mat" a 0.001% probability, so your loss is very high. If you'd given "mat" 99% probability, your loss would be nearly zero.

The loss is a score. Lower is better. The entire training process is a campaign to drive this number down.

A neural network doesn't "understand" anything during training. It just tries, over and over, to make a number smaller. Understanding — or something that looks remarkably like it — emerges as a side effect.

The backward pass: blame flows back through the network

This is where the real magic lives — and where most explanations lose people. But the intuition is surprisingly graspable.

We have a loss. We want to make it smaller. The loss depends on the network's weights. So the question becomes: which weights contributed most to the error, and in which direction should we nudge them?

The backward pass answers this using an algorithm called backpropagation, which is just the chain rule from calculus applied systematically. If you've forgotten the chain rule, here's the gist: if A affects B and B affects C, you can figure out how A affects C by multiplying those two relationships together.

The network works the same way. The loss depends on the output layer's weights. The output layer's values depend on the layer before it. That layer depends on the one before it. Backpropagation starts at the loss and works backward, layer by layer, computing a gradient for every single weight — a tiny arrow that says "move this weight this much in this direction to reduce the loss."

In a model like GPT-4, that means computing gradients for hundreds of billions of weights. Every. Single. Training step.

Once we have the gradients, we apply them. Each weight gets nudged by a small fraction of its gradient (scaled by the learning rate, a hyperparameter that controls how aggressive the updates are). Too large a learning rate and the model overshoots, bouncing around wildly. Too small and training takes forever — or gets stuck.

Putting it together: one step, a trillion times

One forward pass, one loss calculation, one backward pass, one weight update. That's a single training step. Modern LLMs do this millions of times, each time on a different batch of training data — a random sample of, say, a few thousand text passages.

Over those millions of steps, the weights gradually organize themselves into patterns that capture grammar, facts, reasoning heuristics, and all the other capabilities that impress (and occasionally alarm) us. No one explicitly programs "understand sarcasm" or "solve algebra." The forward-backward loop, applied at staggering scale, discovers those behaviors because they reduce the loss.

This is also why scale matters so much. More parameters mean more knobs to adjust, which means the network can fit more subtle patterns. More data means the gradients carry richer information. More compute means more steps through the loop. The scaling laws that dominate AI research right now — including recent work on scaling laws for protein-folding models — are essentially studying how these three ingredients trade off against each other.

💡
Fun fact: Backpropagation was described in various forms in the 1960s and 70s, but it didn't become the standard training algorithm for neural networks until a landmark 1986 paper by Rumelhart, Hinton, and Williams. The math hadn't changed — computers just finally got fast enough to make it useful.

Why this matters for everything else you've read

Knowing the forward-backward loop reframes a lot of concepts you've already encountered:

  • Fine-tuning (from our RAG vs. fine-tune chapter) is just resuming this loop on new, specialized data — starting from weights that are already good, rather than random.
  • Prompt engineering works because the forward pass is deterministic given fixed weights and input — change the input, change the output, no retraining required.
  • Overfitting happens when the backward pass over-optimizes for the training data, reducing the loss on examples the model has seen while getting worse on new ones.

The forward and backward passes are the heartbeat of every neural network. Everything else — attention mechanisms, transformer architectures, RLHF, mixture-of-experts routing — is just a more sophisticated version of what happens inside each pass. But the loop itself? Guess, grade, adjust. That hasn't changed in nearly 40 years.
